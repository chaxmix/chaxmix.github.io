Building RealInsight's design system

RealInsight's loan servicing platform ran for over a decade with no designer and three separate component libraries. I was asked to make it prettier. I built the system first.

Challenges

  1. Selling a foundationLeaders had shipped for a decade without a system. I made the case that it had to come before the redesign, because everything after would be built from it.
  2. Merging without breakingThree libraries had to become one that still works with today's code. I worked directly with our frontend engineer so each swap was seamless.
  3. Covering a huge platformI started with a simpler part of the product, built a foundation set there, and grew the system one use case at a time.

Result

3 → 1component libraries merged into one system
258design tokens, from 12 colour ramps to spacing and radius
970component variants across 30 components
25%of the platform already moved to the new components

What I learned

The ask is rarely the need. "Make it prettier" would have produced nicer screens on the same tangled base. Building the system first was slower to show, but every screen since has been faster and more consistent.

Next time I'd bring engineering leads in even earlier, so adoption starts with the first component instead of after the foundation.
